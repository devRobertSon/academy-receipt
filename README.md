# 교습비등 영수증 생성 도구

수납현황 엑셀(`.xls` / `.xlsx`)을 **여러 개 한 번에** 올리면, 학생별로
**「학원의 설립·운영 및 과외교습에 관한 법률 시행규칙」 별지 제24호서식** 교습비등 영수증을
만들어 인쇄 / PDF 저장할 수 있는 정적 웹페이지입니다. 파일은 브라우저 안에서만 처리됩니다.

## 사용 방법

1. 저장소 루트에 **`수납항목매핑.csv`** (아래 형식)와, 필요하면 도장 이미지 **`seal.png`** 를 둡니다.
2. 배포된 페이지에서 수납현황 엑셀들을 업로드합니다.
3. 미분류 항목이 있으면 교습과목을 입력, 동명이인 의심이 있으면 확인한 뒤 → 영수증 생성.
4. **인쇄 / PDF 저장**.

## 동작 규칙

### 학생 구분 (동명이인)
- 학생은 **이름 + 학년**으로 묶습니다(학년은 엑셀 값이며 영수증에는 표시하지 않습니다).
- 이름·학년이 모두 같은 진짜 동명이인은 데이터로 자동 구분이 불가능하므로,
  **같은 이름+학년에서 같은 수납항목이 그 달에 2번 이상** 나오면 “동명이인 확인” 화면을 띄워
  각 결제에 학생 번호(1·2·3…)를 매겨 분리할 수 있게 합니다(모두 1이면 한 사람).

### 수납항목 → 교습과목·세부반 분류 (3층 구조)
각 `수납항목`을 아래 순서로 분류합니다:

1. **비교습 제외** — `식사·간식·급식·중식·석식` 포함 항목과 `기타수납`은 **완전히 제외**.
2. **CSV 매핑**(`수납항목매핑.csv`, 저장소 루트) — 형식 `키워드,교습과목,세부반`. 키워드가 포함되면 그 값으로 확정(여러 개면 **가장 긴 키워드** 우선). 강사·시간으로만 판단하는 애매한 항목은 여기서 수기 확정.
3. **우선순위 규칙** — CSV에 없으면 문자열에서 **과목 토큰을 정해진 순서로 탐색**(요일·시간·교재명 `쎈/수바/rpm`·강사 이니셜은 무시).
   - 과학: `물리→화학→생명(유전)→지구→통합과학→정보→실험과학→과학정리→영재고파이널→중학과학`
   - 수학 특수(중등 B): `올수지→KMO정수/대수/기하→창의수학→탐구수학/금과고대비→영재모의고사→기출문제`
   - 수학 고등: `공수1→공수2→미적분1→미적분→확통→기하→수2→대수→공수`
   - 교과 fallback: 초등(`EMF/EMM/초등수학`) / 중등(`MMF/MMM/개념유형/중등수학/쎈+학년`) / 고등(`클리닉/문제풀이/방학특강`) → `교과`
   - 과고 계열 → `수학 고등 B`(미적분·확통·교과)
4. **그래도 토큰이 없으면 제외** — 화면 하단 **"영수증 제외 항목"** 목록에 표시(월·항목·건수·금액). 실제 교습이 섞여 있으면 그 항목을 `수납항목매핑.csv`에 추가.

- **교습과목**은 게시표 값만: `과학 중/고`, `수학 {초/중/고} {A/B}`, `진학지도`.
  - 수학 슬롯: **A = 일반 교과 수학**, **B = 특수**(중등: KMO·올수지·영재·과학고대비·창의/탐구수학 / 고등: 과고·자사고 내신).
- **정가는 교습과목 레벨로 자동**(초 200,000 / 중 250,000 / 고 300,000, 진학지도 300,000).

### 영수증 (별지 제24호서식)
과학과 수학을 다르게 처리합니다:

- **과학** — 실제 수납항목대로 한 줄씩. 교습대상 = `과학 초/중/고`, 개설반 = 매칭 키워드(세부 반명, 같은 반 2개↑면 `A`,`B`), 교습비 = 실제 납부액.
- **수학** — 항목별. 같은 (교습과목+세부반)은 **합이 정가 이하일 때만 합산**(분할납 → 한 줄), 정가를 넘으면 서로 다른 반이므로 항목별로 분리. 교습대상 = `수학 {레벨} {A/B}`, 개설반 = 세부반, 교습비 = 실납.
  - 수학 줄이 2개 이상이면 각 줄에 `중복수강 할인 −50,000원`, 정가보다 더 낮으면 남는 차액을 `중복시간 할인 −N원`으로 추가.
- **진학지도**(면접·면담대비)는 실제 항목대로. 교습비 합계 = 실제 납부액 총합.
- 한 수학 줄이 교습과목 정가를 넘으면 정가 이하로 분할합니다(예: 공통수학 900,000 → 300,000×3, 세부반 `공수 A/B/C`).
- 일련번호는 수납월별로 납부일 순, **모든 영수증은 영수일(납부일) 오름차순**으로 정렬됩니다(가장 오래된 날짜가 1페이지).

### 도장(인)
- 저장소 루트에 **`seal.png`** 가 있으면 `(인)` 자리에 자동으로 찍힙니다(없으면 `(인)` 텍스트).

## 배포 (GitHub Pages)
정적 페이지이므로 **Settings → Pages → Deploy from a branch** 에서 브랜치와 폴더(`/root`)를 지정하면 게시됩니다.
xlsx 파싱은 SheetJS(CDN)를 사용하므로 브라우저에서 외부 스크립트 로드가 가능해야 합니다.
