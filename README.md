# 교습비등 영수증 생성 도구

수납현황 엑셀(`.xls` / `.xlsx`)을 **여러 개 한 번에** 올리면, 학생별로
**「학원의 설립·운영 및 과외교습에 관한 법률 시행규칙」 별지 제24호서식** 교습비등 영수증을
만들어 인쇄 / PDF 저장할 수 있는 정적 웹페이지입니다. 파일은 브라우저 안에서만 처리됩니다.

## 사용 방법

1. 저장소 루트에 **`수납항목매핑.csv`** (아래 형식)와, 필요하면 도장 이미지 **`seal.png`** 를 둡니다.
2. 배포된 페이지에서 수납현황 엑셀들을 업로드합니다.
3. 미분류 항목이 있으면 교습과목을 입력, 동명이인 의심이 있으면 확인한 뒤 → 영수증 생성.
4. **인쇄 / PDF 저장**.

## 동작 규칙

### 학생 구분 (동명이인)
- 학생은 **이름 + 학년**으로 묶습니다(학년은 엑셀 값이며 영수증에는 표시하지 않습니다).
- 이름·학년이 모두 같은 진짜 동명이인은 데이터로 자동 구분이 불가능하므로,
  **같은 이름+학년에서 같은 수납항목이 그 달에 2번 이상** 나오면 “동명이인 확인” 화면을 띄워
  각 결제에 학생 번호(1·2·3…)를 매겨 분리할 수 있게 합니다(모두 1이면 한 사람).

### 수납항목 → 교습과목 매핑 (`수납항목매핑.csv`, 저장소 루트)
- 형식: `키워드,교습과목,정가` (저장소에 11개월치 데이터로 만든 실매핑이 들어 있습니다.)
- 각 `수납항목`에 **키워드가 포함**되면 그 교습과목으로 매핑합니다. 여러 개가 걸리면 **가장 긴 키워드** 우선.
- **교습과목은 게시표(별지 제7호) 값만** 사용합니다: `과학 초등/중등/고등`, `수학 초등/중등/고등`, `진학지도`, 그리고 `기타경비`.
- **정가는 교습과목별로 자동** 적용됩니다(과학·수학 초 200,000 / 중 250,000 / 고 300,000, 진학지도 300,000). CSV의 정가 열은 참고용입니다.
- **레벨 미지정 규칙**: 교습과목을 `수학`/`과학`처럼 **레벨 없이** 적으면(예: 방학특강), 그 결제 **학생의 학년**으로 레벨(초/중/고)을 붙입니다.
- **기타경비**: 교습과목을 `기타경비`로 두면(예: 식사비) 교습비(A)가 아니라 **기타경비(B)** 란에 표기됩니다.
- 어디에도 매칭되지 않는 항목과 **기타수납**은 **영수증 생성 전에 직접 입력**해야 합니다. (`기타수납`은 건마다 내용이 달라 **건별 수기**)

### 영수증 (별지 제24호서식)
- 표의 각 줄 = 실제 수납항목 1건. **교습대상** = 매핑된 교습과목, **개설반** = 매칭 키워드(세부 반명), **교습비** = 실제 납부액.
- 같은 교습과목+같은 키워드를 2개 이상 들으면 개설반에 `A`, `B` … 를 붙입니다.
- **중복수강 할인**: 교습과목을 2개 이상 듣는 학생의 줄에서 `정가 − 납부액 > 0` 이면
  비고에 `중복수강 할인 −(차액)원` 을 적습니다(회차 등으로 차액은 5만원이 아닐 수 있음).
- 일련번호는 수납월별로 납부일 순, **모든 영수증은 영수일(납부일) 오름차순**으로 정렬됩니다(가장 오래된 날짜가 1페이지).

### 도장(인)
- 저장소 루트에 **`seal.png`** 가 있으면 `(인)` 자리에 자동으로 찍힙니다(없으면 `(인)` 텍스트).

## 배포 (GitHub Pages)
정적 페이지이므로 **Settings → Pages → Deploy from a branch** 에서 브랜치와 폴더(`/root`)를 지정하면 게시됩니다.
xlsx 파싱은 SheetJS(CDN)를 사용하므로 브라우저에서 외부 스크립트 로드가 가능해야 합니다.
