# 수강료 납부 현황 집계 도구

수납 현황 엑셀(`.xls` / `.xlsx`)을 업로드하면 **① 월별 학생 납부액 총합 CSV**를 만들고,
그 CSV로 **② 학생별 교습비등 영수증(별지 제24호서식)** 까지 만들어 주는 정적 웹페이지입니다.
파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

## 사용 방법

1. 배포된 페이지 접속
2. **1단계**: 수납 현황 엑셀을 올리고, 학년 확인 후 월별 CSV 다운로드
3. **2단계**: 받은 월별 CSV(여러 개 가능)를 올려 학생별 영수증을 만들고 인쇄 / PDF 저장

## 1단계 출력 (현재 구현)

`번호, 이름, 학년, 납부액총합, 영수일자` 5개 열의 CSV (UTF-8 BOM, 엑셀에서 바로 열림).
`영수일자`는 그 학생·월 결제 중 **가장 늦은 납부일**(엑셀 `납부일`)이며, 2단계 영수증에 자동 기입됩니다.

하나의 엑셀 파일에 여러 **수납월**이 섞여 있어도 월별로 나눠 **각 수납월마다 CSV 1개**를 만듭니다.
파일명은 `학생별_납부액총합_YYYY-MM.csv` 형식이라 2단계에서 월을 그대로 인식할 수 있습니다.

### 집계 규칙

- 입력 시트에서 헤더(`NO`·`이름`·`납부액`)를 자동으로 찾고, `NO`가 채워진 행을 결제 1건으로 봅니다.
- `수납월` 열 기준으로 월을 나눈 뒤, 월 안에서 학생별로 합계를 냅니다.
- **학년 확인·직접 입력**: 학년이 비어 있거나 초/중/고로 시작하지 않는 학생은 "확인 필요"로 표시되며,
  화면에서 학년을 직접 입력하면 CSV·미리보기에 즉시 반영됩니다. (2단계 영수증은 학년으로 밴드를
  판별하므로 여기서 바로잡아 두면 이후 처리가 정확해집니다.)
- 한 학생이 여러 수업을 들으면 `반` 열이 병합 셀로 수강 반 목록이 나열되며, 이름·학년·납부액은 각 결제 행에서 읽습니다.
- **동명이인 구분**: ① 이름 → ② 학년 → ③ 반 목록 순서로 서로 다른 학생을 분리합니다.
- **환불 처리**: 기본값은 `상태='환불'` 건을 합계에서 **제외**(체크박스로 변경 가능). 제외 시 총합이 엑셀 요약의 `납부총액`과 일치합니다.

## 2단계 출력 — 교습비등 영수증 (별지 제24호서식)

1단계에서 만든 **월별 CSV(여러 개 동시 업로드 가능)** 를 올리면, 학생별·월별로
**「학원의 설립·운영 및 과외교습에 관한 법률 시행규칙」 별지 제24호서식** 형식의
교습비등 영수증을 화면에 만들고, **인쇄 / PDF 저장** 버튼으로 출력할 수 있습니다.

### 영수증 산출 규칙

- 학년으로 밴드(초/중/고)를 정하고, 교육청 신고 단가(초 200,000 / 중 250,000 / 고 300,000,
  과학·수학 동일 / 진학지도 300,000 정액)로 과목반을 **정가**로 채웁니다.
- **채우는 순서**: 고등생 `고→중→초`, 중등생 `중→고→초`, 초등생 `초→중→고`.
  각 학년 세그먼트 안에서는 `수학 A → 과학 → 수학 B` 순서입니다.
  (본인 학년으로 먼저 채우고, 금액이 넘으면 낮은 학년 과목을 추가 — 매월 같은 순서라
  방학 등으로 금액이 오른 달에만 뒤쪽 과목이 추가되어 과목 연속성이 유지됩니다.)
- **잔액 처리**: 과목반 정가로 채운 뒤 남는 금액(항상 0~300,000원)은 **진학지도** 한 줄로 넣고
  정가 300,000원에서 그만큼 **할인**한 것으로 표시합니다. 과목 교습비는 할인하지 않습니다.
- 실납부액과 영수증 합계가 **정확히 일치**합니다(신고 가능한 최대 2,350,000원 이내).
  학년이 비어 있으면 과목을 배정할 수 없으므로 1단계에서 학년을 입력해 두세요.
- **일련번호**는 수납월 단위 발급번호(`YYYY-MM-NNN`), **연월**은 수납 연월, **영수일자**는
  CSV의 값(최종 납부일)을 자동으로 적습니다. 값이 없으면 연·월만 인쇄하고 '일'은 공란으로 둡니다.

## 배포 (GitHub Pages — Deploy from a branch)

정적 페이지(`index.html`)이므로 저장소 **Settings → Pages → Build and deployment**에서
**Source: Deploy from a branch** 를 선택하고, 브랜치와 폴더(`/root`)를 지정하면 게시됩니다.
